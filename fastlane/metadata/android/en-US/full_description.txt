Kryptos encrypts messages directly inside the chat, so you never have to switch between apps.

The Kryptos keyboard installs like any other system keyboard: enable it once, and it will be available everywhere you type. Write a message in WhatsApp, Telegram, or SMS, tap the lock icon, and the text in the input field is instantly replaced with ciphertext ready to send. Incoming messages are decrypted automatically, directly on top of the chat as you scroll, with no copying or app switching required. Both the keyboard and on-screen decryption are built into the system, so they work in any app.

Encryption: the Signal Protocol, powered by the official Signal libsignal library, a new key for every message, and protection against future quantum computers. Contacts can be verified using a safety code. If a full chat protocol is more than you need, there is a simple mode based on a shared password. PGP is also built in for users who rely on it. To the messenger, the encrypted message looks like nothing more than a meaningless string of characters with no recognizable markers.

Steganography hides the very fact that a message was written. Encrypted text can be hidden inside an ordinary photo or disguised as a harmless-looking sequence of real words. Without the password, the hidden content cannot be extracted from the image.

Nothing connects to the internet: the app contains no networking code. Kryptos requests only the permissions it needs for QR code scanning, vibration, and overlay functionality. No accounts, phone numbers, servers, or analytics. Keys are generated directly on the device, stored in Android’s secure keystore, and never leave it.

Access to the app can be protected with biometrics or a password. There is also a panic-wipe password: entering it into the same password field permanently deletes all stored data. The clipboard is cleared automatically, messages can be set to disappear after a timer, and screenshots and the app preview in the recent-apps screen can be blocked. All your keys can also be exported to a single password-protected file for transfer to a new phone.

Also included: light and dark themes, multiple app languages, a step-by-step guide with answers to frequently asked questions, emoji support, and fully offline autocorrect for English, Russian, German, and Persian, plus pinyin input for Chinese.
