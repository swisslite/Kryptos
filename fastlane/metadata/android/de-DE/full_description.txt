Kryptos verschlüsselt Nachrichten direkt im Chat, sodass Sie nie zwischen verschiedenen Apps wechseln müssen.

Die Kryptos-Tastatur wird wie jede andere Systemtastatur installiert: Aktivieren Sie sie einmal, und sie steht überall dort zur Verfügung, wo Sie Text eingeben. Schreiben Sie eine Nachricht in WhatsApp, Telegram oder per SMS, tippen Sie auf das Schloss-Symbol, und der Text im Eingabefeld wird sofort durch einen versandbereiten Geheimtext ersetzt. Eingehende Nachrichten werden automatisch direkt über dem Chat entschlüsselt, während Sie durch den Chat scrollen, ohne dass Sie etwas kopieren oder die App wechseln müssen. Sowohl die Tastatur als auch die Entschlüsselung direkt auf dem Bildschirm sind in das System integriert und funktionieren daher in jeder App.

Verschlüsselung: das Signal-Protokoll, unterstützt durch die offizielle Signal-libsignal-Bibliothek, ein neuer Schlüssel für jede Nachricht und Schutz vor zukünftigen Quantencomputern. Kontakte können mithilfe eines Sicherheitscodes verifiziert werden. Wenn Sie kein vollständiges Chat-Protokoll benötigen, gibt es einen einfachen Modus, der auf einem gemeinsamen Passwort basiert. Für Nutzer von PGP ist auch PGP integriert. Für den Messenger sieht die verschlüsselte Nachricht lediglich wie eine bedeutungslose Zeichenfolge ohne erkennbare Merkmale aus.

Steganografie verbirgt bereits die Tatsache, dass überhaupt eine Nachricht geschrieben wurde. Verschlüsselter Text kann in einem gewöhnlichen Foto versteckt oder als harmlos wirkende Folge echter Wörter getarnt werden. Ohne das Passwort kann der versteckte Inhalt nicht aus dem Bild extrahiert werden.

Keine Verbindung zum Internet: Die App enthält keinen Netzwerkcode. Kryptos fordert nur die Berechtigungen an, die für das Scannen von QR-Codes, Vibrationen und die Overlay-Funktion benötigt werden. Keine Konten, Telefonnummern, Server oder Analysedienste. Die Schlüssel werden direkt auf dem Gerät erzeugt, im sicheren Android-Keystore gespeichert und verlassen das Gerät niemals.

Der Zugriff auf die App kann mit biometrischer Authentifizierung oder einem Passwort geschützt werden. Es gibt außerdem ein Notfall-Löschpasswort: Wird es in dasselbe Passwortfeld eingegeben, werden alle gespeicherten Daten dauerhaft gelöscht. Die Zwischenablage wird automatisch geleert, Nachrichten können so eingestellt werden, dass sie nach einer bestimmten Zeit automatisch gelöscht werden, und Screenshots sowie die App-Vorschau in der Ansicht der zuletzt verwendeten Apps können blockiert werden. Alle Ihre Schlüssel können außerdem in eine einzige passwortgeschützte Datei exportiert werden, um sie auf ein neues Smartphone zu übertragen.

Ebenfalls enthalten: helle und dunkle Designs, mehrere App-Sprachen, eine Schritt-für-Schritt-Anleitung mit Antworten auf häufig gestellte Fragen, Emoji-Unterstützung sowie vollständig offline funktionierende Autokorrektur für Englisch, Russisch, Deutsch und Persisch und Pinyin-Eingabe für Chinesisch.
